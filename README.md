# General Info
* This song uses Tunepad and Python to code Fur Elise, and then a transition into an upbeat modern remix.
* This addresses my artistic challenge to transform a classical composition into an upbeat mix, while still retaining the classic essence of Beethoven's song.

# Technologies Used 
* Tunepad

# Features
* Loops
* Change in velocity
* Defining lines of code
* Remixes fazing in and out with a change in beat durations

# Usage 
Can be accessed through the uploaded MP3 file and the uploaded link to Tunepad.
